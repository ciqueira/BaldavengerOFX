# Complete Corresponding Source

The complete corresponding source for Nexus-distributed BaldavengerOFX
binaries is maintained at:

https://github.com/ciqueira/BaldavengerOFX

Each binary release must identify the exact Git tag or commit used to build it.
The matching source must remain available without an additional charge and
include the source files, build configuration, scripts, and fork modifications
needed to rebuild that version, subject to the GNU GPLv3 definition of
Corresponding Source.

The moving default branch alone is not a release identifier. A user looking at
a binary release should be able to follow its tag or commit link and retrieve
the matching source version. If a release contains generated or vendored
material required by GPLv3 Corresponding Source, that material must also be
available from the release or the identified source tree.
