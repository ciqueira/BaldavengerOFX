# Fork Modifications

This fork preserves the BaldavengerOFX project under GNU GPLv3 and includes
changes intended to maintain and distribute selected plugins through MCNexus.

The fork history currently includes work such as:

- macOS Metal and Windows CUDA build maintenance;
- CUDA toolchain updates;
- Windows build and compatibility fixes;
- release workflows and machine-readable release manifests;
- per-plugin version files;
- selection and packaging of the plugins listed in the README; and
- Nexus distribution, MCNexus app, and technical-key documentation.

This summary is not a substitute for the Git history. Each release tag and its
commit history identify the exact changes included in that binary release.

The original upstream is:
https://github.com/baldavenger/BaldavengerOFX
